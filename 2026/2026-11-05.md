## Esquemas que se pueden trabajar en clase

- **Red externa → Firewall → Red interna**
  - Arquitectura básica de protección perimetral.
  - Análisis de reglas de filtrado.
  - Identificación de puertos y servicios expuestos.

- **Red externa → Firewall → DMZ → Red interna**
  - Arquitectura de subred protegida.
  - Separación entre servicios públicos y recursos internos.
  - Análisis de los flujos permitidos entre zonas.

- **Red externa → Firewall externo → DMZ → Firewall interno → Red interna**
  - Arquitectura fuerte de subred protegida.
  - Defensa en profundidad.
  - Separación de responsabilidades entre los diferentes elementos de seguridad.

- **Usuario remoto → VPN → Perímetro de red → Recursos internos**
  - Acceso remoto seguro.
  - Autenticación.
  - Cifrado de las comunicaciones.
  - Control de los recursos accesibles mediante la VPN.

- **Internet → Firewall/Proxy → DMZ → Firewall interno → Red corporativa**
  - Publicación segura de servicios.
  - Filtrado de tráfico.
  - Segmentación.
  - Monitorización.
  - Registro de eventos.

# Implantación de seguridad perimetral

## Introducción

La **seguridad perimetral** comprende el conjunto de mecanismos destinados a controlar, filtrar, proteger y supervisar las comunicaciones entre diferentes redes o zonas de seguridad.

Tradicionalmente se ha utilizado para proteger una red interna frente a redes externas consideradas menos confiables, especialmente Internet.

La seguridad perimetral puede incluir diferentes elementos:

- Cortafuegos.
- Sistemas bastión.
- Proxys.
- VPN.
- Sistemas IDS/IPS.
- Routers y dispositivos de filtrado.
- Segmentación de redes.
- Zonas desmilitarizadas o DMZ.
- Sistemas de monitorización.

La idea fundamental es establecer **puntos de control entre diferentes zonas de confianza**.
