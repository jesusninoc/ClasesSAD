# Adopción de pautas de seguridad informática

## Desarrollo ampliado

### 1. Principios de seguridad
- Confidencialidad: impedir el acceso no autorizado a la información.
- Integridad: garantizar que la información no ha sido modificada de forma no autorizada.
- Disponibilidad: asegurar que los servicios y datos estén accesibles cuando sean necesarios.
- Autenticidad: comprobar que una identidad, sistema, mensaje o recurso es quien dice ser.
- Trazabilidad: poder relacionar acciones con usuarios, sistemas, procesos y momentos concretos.
- No repudio: disponer de mecanismos que permitan acreditar la realización de determinadas acciones.

### 2. Activos, amenazas, vulnerabilidades y riesgos
- Activos: hardware, software, información, servicios, comunicaciones, credenciales y personas.
- Amenaza: circunstancia o agente capaz de producir un daño.
- Vulnerabilidad: debilidad susceptible de ser aprovechada.
- Riesgo: combinación de probabilidad e impacto asociada a una amenaza.
- Impacto: consecuencias sobre la organización, los datos, los servicios, las personas o la continuidad.
- Controles preventivos, detectivos, correctivos y compensatorios.
- Riesgo inherente y riesgo residual.
- Inventario de activos y clasificación de la información.
- Análisis cualitativo y cuantitativo del riesgo.

### 3. Seguridad física y ambiental
- Control de acceso físico.
- Cerraduras, tarjetas, biometría y registros.
- Videovigilancia y control de visitantes.
- Protección frente a incendio, humo, agua, polvo y temperatura.
- Refrigeración y monitorización ambiental.
- Redundancia eléctrica.
- SAI/UPS y grupos electrógenos.
- Protección frente a sobretensiones.
- Ubicación de servidores y comunicaciones.
- Plan de continuidad y recuperación ante desastres.
- RTO (Recovery Time Objective) y RPO (Recovery Point Objective).

### 4. Seguridad lógica
- Identificación, autenticación y autorización.
- MFA/2FA.
- Principio de mínimo privilegio.
- Separación de funciones.
- Control de sesiones.
- Gestión del ciclo de vida de cuentas.
- Políticas de contraseñas y gestores de contraseñas.
- Hash frente a cifrado.
- Cifrado simétrico y asimétrico.
- Firmas digitales.
- Certificados y PKI.
- Gestión de claves.
- Rotación y revocación de credenciales.
- BitLocker y otros mecanismos de cifrado de almacenamiento.
- Control de integridad mediante hashes.

### 5. Almacenamiento y copias de seguridad
- DAS, NAS y SAN.
- RAID y tolerancia a fallos.
- Copias completas, incrementales y diferenciales.
- Regla 3-2-1.
- Copias offline e inmutables.
- Cifrado de copias.
- Verificación de restauración.
- Inventario de copias.
- Pruebas periódicas de recuperación.
- Relación entre backup, alta disponibilidad y continuidad: una réplica no sustituye necesariamente a una copia de seguridad.

### 6. Análisis forense
- Preservación de evidencias.
- Integridad mediante hashes.
- Adquisición.
- Análisis de disco y memoria.
- Timeline.
- Logs.
- Navegadores.
- USB.
- Metadatos.
- Indicadores de compromiso.
- Documentación y cadena de custodia.
- Diferencia entre análisis forense y monitorización preventiva.

## Ejecutar un comando remotamente utilizando un servidor web creado en PowerShell
```Powershell
$routes = @{
    "/" = { return '<html><body>Servidor web funcionando</body></html>' }
}

#Importante poner la IP de la red privada
$url = 'http://192.168.204.222:8027/'
$listener = New-Object System.Net.HttpListener
$listener.Prefixes.Add($url)
$listener.Start()

Write-Host "Funcionando $url..."

while ($listener.IsListening)
{
    $context = $listener.GetContext()
    $requestUrl = $context.Request.Url
    $response = $context.Response

    Write-Host ''
    Write-Host "Petición: $requestUrl"

    $localPath = $requestUrl.LocalPath
    $route = $routes.Get_Item($requestUrl.LocalPath)

    if ($route -eq $null)
    {
        $response.StatusCode = 404
    }
    else
    {
        
        $content = & $route
        $buffer = [System.Text.Encoding]::UTF8.GetBytes($content)
        $response.ContentLength64 = $buffer.Length
        $response.OutputStream.Write($buffer, 0, $buffer.Length)
    }
    
    $response.Close()
    start-process ($context.Request.RawUrl -replace "/")
    $context.Request.RawUrl
    $responseStatus = $response.StatusCode
    Write-Host "Respuesta: $responseStatus"
}
```

### Get-CimInstance
While Get-WmiObject always uses DCOM as a transport protocol, Get-CimInstance uses WSMan (a webservice-type of communication). Most modern Windows systems support WSMan, but if you need to contact older servers, they may only respond to DCOM, thus Get-CimInstance may fail.

Get-CimInstance can use session options, however, that provide great flexibility, and allow you to choose the transport protocol. In order to use DCOM (just like Get-WmiObject), do the following:

```PowerShell
$options = New-CimSessionOption -Protocol Dcom 
$session = New-CimSession -ComputerName sr0710 -SessionOption $options
$sh = Get-CimInstance -ClassName Win32_Share -CimSession $session 
Remove-CimSession -CimSession $session
```

Here is an example illustrating how the same session is used for two queries:
http://community.idera.com/powershell/powertips/b/tips/posts/wmi-quick-primer-part-3
```PowerShell
# create the session 
$options = New-CimSessionOption -Protocol Wsman 
$session = New-CimSession -ComputerName sr0710 -SessionOption $options
 
# reuse the session for as many queries as you like 
$sh = Get-CimInstance -ClassName Win32_Share -CimSession $session -Filter 'Name="Admin$"' 
$se = Get-CimInstance -ClassName Win32_Service -CimSession $session
 
# remove the session at the end 
Remove-CimSession -CimSession $session
```

## Criterio de seguridad para todas las prácticas

Las prácticas ofensivas deben realizarse exclusivamente en:
- máquinas propias;
- máquinas virtuales;
- contenedores;
- CTF;
- aplicaciones vulnerables de laboratorio;
- dispositivos propios;
- redes de laboratorio;
- sistemas con autorización expresa.

La finalidad de la práctica debe quedar definida: comprender una técnica, identificar indicadores, validar una configuración, analizar una vulnerabilidad o comprobar una contramedida.
